# 口播视频复刻全流程总结

> 整理时间：2026-11-11
> 用途：主人核对流程用，之后做成开源项目
> 涉及：Seedance 口播拆解 Skill + 菠萝 BOLO 工作流

---

## 一、流程总览

```
用户发口播视频
  → 助手调用 seedance-presenter-breakdown Skill 拆解
  → 得到两样东西：① 生成提示词 ② 完整口播台词
  → 在 BOLO 里复刻一份工作流（不碰原版）
  → 把提示词填进可灵 Omni 节点（选 15 秒）
  → 把台词填进文本输入节点
  → TTS 音色按主播性别匹配（男→男声，女→女声）
  → 命名（标题旁铅笔图标）→ 保存
  → 生产信息：账户 ID、生产数量**要问客户确认**（当前临时填 1 占位，不是定值）
  → 点 466 生产（466 积分一次）
```

**核心逻辑（一句话）：**生成 15 秒不张嘴的人物，动一动，然后倒放循环延长到台词时长，再把文字转成语音跟视频对口型。

## 二、第一步：拆解视频（Seedance Skill）

Skill 位置：`~/workspace/custom-skills/seedance-presenter-breakdown/`
开源仓库：https://github.com/wangchangxin521-spec/seedance-presenter-breakdown（公开，2026-11-11 创建）

### 2.1 输出格式（固定两段）

- **生成提示词：**一段完整的不张嘴口播人物提示词
- **完整口播台词：**原文台词按原顺序连成一段，不分行、不编号、不加时间戳

### 2.2 提示词模板要点

- 中国人，年龄段与视频相近，性别明确，身份贴合主题（如口腔健康讲解、种植牙讲解）
- 站立，样貌不固定，服装接近原视频气质、可变化
- 场景接近原视频类型、光线和主要元素，具体布置可变化
- **不说话**：嘴唇全程自然闭合，不张嘴，不做说话口型，不露牙齿
- 只做轻微讲解动作，双手在腰腹附近小幅度示意，动作轻缓、有自然停顿，身体稳定
- 全程直视镜头，自然眨眼，表情自然，**不微笑，不大喘气**（不要写「呼吸平稳」）

### 2.3 左右晃动：看参考视频，不是必备

- 原视频人物有轻微左右晃动 → 才写「上半身轻微左右晃动，晃动缓慢均匀，首尾动作可自然衔接，适合倒放循环延长至台词时长」
- 原视频人物静止 → 不写
- 写了就要缓慢均匀、幅度小，能倒放循环、无明显跳变；不要写成大幅摇摆或左右走动

### 2.4 台词：以音频为准

- 台词从视频**音频**里转写，不是从字幕抄
- 字幕只用来核对专业词、数字、容易听错的词
- 画面上的标题、贴纸、声明文字（没说出来的）一律不写进台词
- 不润色、不改写原话

### 2.5 校验方法（血的教训）

- 视频要**完整解码验证**（时长、帧数、分辨率），不能只看文件头就夸「完整」
- ASR 用本地 faster-whisper（small 模型，`~/workspace/models/faster-whisper-small`，venv `~/workspace/venvs/asr`），音频先转 16k 单声道 wav
- 关键句拿两个模型（small + base）或结合字幕二次核对
- 人物/场景以实际抽帧为准，不凭印象发明

## 三、第二步：BOLO 工作流

平台：菠萝 BOLO（bolo.kwailocallife.com），创建人 wb_wangchangxin

### 3.1 节点链（已连好，不用改）

```
文本输入 → TTS音色-情绪调节（IndexTTS2）→ 视频对口型（HeyGen）
可灵 Omni 生视频 → 视频对口型 → 添加字幕 → 视频转码
文本输入 → 添加字幕
```

### 3.2 可灵 Omni 节点配置

| 项 | 值 |
|---|---|
| 模型名称 | Kling V3 Omni |
| 提示词 | 直接输入（填拆解出的生成提示词） |
| 视频时长 | **15 秒** |
| 生成模式 | Pro（1080P） |
| 宽高比 | 9:16 |
| 生成声音 | 关闭 |
| 参考图片 | 未设置 |

### 3.3 文本输入节点

填完整口播台词（一段到底）。TTS 节点是连接模式，源节点就是文本输入。

### 3.4 TTS 音色（按性别 + 年纪一起匹配）

| 主播 | 音色 |
|---|---|
| 女，中年 | 沙哑激情中年女声（速 1.0，音 1.0，调 0.0） |
| 男，中青年 | 成熟稳重中年男声（速 1，音 1，调 0） |

性别和年纪都要对上，不能只看性别。

### 3.5 生产信息（点「466 生产」后弹框）

| 项 | 值 |
|---|---|
| 账户 ID | **问客户确认**（现在临时填 1 占位，不是主人的账号，别当真） |
| 生产数量 | **问客户确认**（现在临时填 1 占位） |
| 备注 | 选填，可空 |

单次消耗 466 积分明细：对口型 5 + TTS 3 + 文本输入 1 + 可灵 Omni 生视频 450（每秒 30 积分 × 15 秒）+ 视频转码 2。

## 八、注意事项

1. **原版 49429 是底版**，永远只复刻、不直接改
2. **每次做完先命名再保存**，不要留着「副本_…」或「未命名」过夜
3. 晃动不是必备，看参考视频有没有再决定写不写
4. 台词以音频为准，字幕只做核对；画面贴纸文字不进台词
5. 生产要花 466 积分，点生产前先问客户确认账户 ID 和生产数量（现在临时填的 1 只是占位，不能当真）
6. BOLO 里没有 LLM / 视频理解 / 转录节点，拆解必须在 BOLO 外面做（Skill + 本地 ASR），只把结果填进去
7. GitHub 上的 Skill 还没同步最新的晃动修正（本地已改，仓库还是旧版），开源前记得同步
8. **并行优化（2026-11-11 主人定的）**：下次做新视频，拆解视频和 BOLO 复刻同时跑——本地转写和浏览器复刻互不依赖，填表那步才需要等拆解结果，这样一份能省一两分钟
9. 点「466 生产」会先自动保存再弹生产信息，不用提前满世界找保存按钮；工具栏的保存图标没标字，不好找
10. BOLO 的活要在主人 Mac 的 Chrome 里做（电脑控制），云端浏览器登的不是他的 BOLO 账号；Mac 那边 Chrome 开着也可能一时连不上，多试一次就行
11. **首页搜完直接点卡片，不用下滑**（2026-11-11 主人纠正）：搜到工作流后卡片就在下面，直接点就行，下滑是多余的
12. **查结果去首页「任务」看生产任务状态，别去工作流的「执行生产记录」里找**（2026-11-11 主人纠正：生产账户不是主人的，工作流里找不到）。点完「466 生产」确认后，要核实真的提交了——任务列表里出现新任务才算，只看表单关了不算（2026-11-11 49561 就是点了确认但没点到，根本没提交）
13. **主工作流 49429 是已发布的公开工作流**（2026-11-11 主人确认）：别人搜名字「口播复刻-可灵Omni+TTS对口型」就能找到并复刻，不用重建节点链
