# Seedance 口播视频拆解

把一条口播参考视频，变成一条能直接用的 Seedance 无声人物生成提示词，外加一段按原顺序提取的完整口播台词。

**使用场景**：你是菠萝 BOLO 的客户，想把别人的口播视频复刻成自己的版本。把这个项目装到豆包上，之后把视频发给豆包，豆包自己拆解，你拿到提示词和台词，再去 BOLO 里复刻模板、填进去、生产。

## 用起来是什么样

1. 小白把项目装到豆包上，一次性把本地环境装好（下面有一步到位的脚本）。
2. 有视频就发给豆包，豆包自己跑脚本抽音频、抽帧、转写，再按规则写出提示词和台词。
3. 你拿着这两段文字去 BOLO：搜公开模板复刻，填三处，改名保存，点生产。
4. 生产完去 BOLO 首页「任务」里看状态，成功就是待推送。

## 安装到豆包

装一次就行。豆包电脑版 →「插件·技能·伙伴」→「技能」→「+ 添加」→「上传技能」，把本项目文件夹（或打包的 zip）拖进去，不用解压。装之前确认文件夹里有 `SKILL.md`，开头写了技能名称和描述。

也可以直接跟豆包说一句话，让它自己装这个 GitHub 仓库；或者把 `SKILL.md` 的 raw 链接发给豆包，让它照着新建一个同名技能。

装好后，在豆包里新建工作任务，工作设备选**本地电脑**，授权本项目文件夹，启用 `seedance-presenter-breakdown` 这个技能。这样豆包才能在你电脑上跑拆解脚本。

## 一次性准备（本地环境）

在项目根目录跑一次就行，之后所有视频共用：

```bash
bash scripts/setup.sh
```

它会做四件事：检查 Python 3 和 ffmpeg、建一个项目自带的 `.venv` 并装 faster-whisper、下载转写模型到 `models/faster-whisper-small`、最后自检一次。国内下载模型慢，可以先 `export HF_ENDPOINT=https://hf-mirror.com` 再跑。

没有 ffmpeg 会直接告诉你怎么装：macOS 用 `brew install ffmpeg`，Windows 用 `winget install Gyan.FFmpeg`，Ubuntu 用 `sudo apt install ffmpeg`。

## 发视频给豆包之后

豆包收到口播视频，会自己做这些事：

1. 跑 `scripts/breakdown.py <视频>`：校验视频能不能完整解码，抽 16k 单声道音频，每 10 秒抽一帧，本地 faster-whisper 转写，输出到 `work/<视频名>/`（`audio-16k.wav`、`frame-*.jpg`、`transcript.json`、`meta.json`）。
2. 看抽帧定人物、场景和有没有晃动；读转写结果，以音频为准核对台词。
3. 按 `SKILL.md` 的固定结构输出两段：`生成提示词：`和`完整口播台词：`，再附一行 BOLO 用的 TTS 音色建议（按性别+年龄匹配）。

没有本地执行能力时，豆包用自带的视频理解、抽帧和转写能力走同样流程。视频读不了、没有音轨或关键内容听不清，豆包会如实说缺什么，不会凭文件名或常见广告词补写台词。

想手动跑脚本也行：`.venv/bin/python scripts/breakdown.py <你的视频>.mp4`，转写结果在 `work/<视频名>/transcript.json`。

## 然后去 BOLO

拆解只解决「提示词 + 台词」，BOLO 里生产那几步要在 BOLO 自己做（要登录你自己的 BOLO 账号、花你账号的积分，豆包替不了）：

1. BOLO 首页搜主工作流名 `口播复刻-可灵Omni+TTS对口型`，直接点结果卡片，进详情页点「复刻工作流」。这是已发布的公开模板，搜名字就能找到并复刻，不用重建节点链。
2. 填三处：可灵 Omni 节点填提示词，文本输入节点填台词，TTS 节点按建议选音色。
3. 改名，保存。
4. 点「466 生产」，填账户 ID 和生产数量（跟客户确认），466 积分/次。点完确认真的提交了：BOLO 首页「任务」里出现新任务才算。
5. 查结果去 BOLO 首页「任务」里看，别去工作流的「执行生产记录」里找（生产账户不是你的，工作流里找不到）。

完整版流程、每个节点的设置和已经跑过的实例，见 [docs/口播复刻全流程总结-2026-11-11.md](docs/口播复刻全流程总结-2026-11-11.md)。

## 硬性条件

- **BOLO 账号**：bolo.kwailocallife.com，能进 studio。TTS、对口型、可灵都在 BOLO 里面，不用单独注册可灵、HeyGen 的账号。
- **积分**：每次生产固定 466 积分（对口型 5 + TTS 3 + 文本输入 1 + 可灵 Omni 450 + 转码 2），账号里得有余额。拆解在本地做，不花钱。
- **本地环境**：Python 3.9+、ffmpeg、约 500MB 模型空间。跑 `scripts/setup.sh` 一次装好。
- **参考视频**：一条竖屏 9:16 的口播视频，声音清楚、单人出镜，镜头最好是固定的。
- **硬限制**：可灵一次只生成 15 秒，靠倒放循环延长到台词长度；音色必须按性别+年龄匹配；晃动只有参考视频里有才写；生产要填账户 ID 和生产数量，得跟客户确认；BOLO 里没有 LLM、视频理解、转录节点，拆解必须在外面做完再填进去。

## 常见问题

- **提示词里为什么不写具体长相？** 样貌不固定，方便批量生成换人；人物身份、年龄段、性别、服装气质、场景按原视频写。
- **晃动写不写？** 看参考视频：原视频有轻微左右晃动才写，没有就不写；写了就要缓慢均匀、幅度小，能倒放循环。
- **台词以什么为准？** 以音频为准，字幕只用来核对专业词、数字和容易听错的词；画面上没说出口的标题、贴纸文字不进台词。
- **生产点了没反应？** 点完确认要去 BOLO 首页「任务」里看有没有出现新任务，没有就是没点到，重新点。
- **账户 ID 填什么？** 问客户确认，现在临时填的 1 只是占位，不是你的账号，别当真。
